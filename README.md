\# D\&D 5e Character Sheet



A digital character sheet for Dungeons \& Dragons 5th Edition.



\## Features



\- Character information and ability scores

\- Automatic skill and saving throw calculations

\- Spellbook and spell-slot tracker

\- Equipment and attacks

\- Automatic initiative and passive perception

\- Save and load characters using JSON files

\- Browser autosaving



\## Website



This project is hosted using GitHub Pages.
